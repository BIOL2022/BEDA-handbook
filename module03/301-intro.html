Introduction

Author

Mathew Crowther

1 Learning objectives

In Module 3 practicals, you will explore several commonly used techniques for analysing multivariate data. By the end of the series, you will be able to:

  • Explain the principles underlying principal components analysis (PCA) and non-metric multidimensional scaling (nMDS).
  • Describe how permutation-based techniques such as ANOSIM and PERMANOVA are used to test multivariate hypotheses.
  • Plan and conduct experiments that test multivariate hypotheses.
  • Carry out these analyses using relevant statistical software.
  • Interpret, present, and report your findings clearly and effectively.

2 Why use multivariate analyses?

Software makes multivariate analyses easier to run, but choosing an appropriate method and interpreting its results still requires care. As discussed in lectures, you need to understand when and how to use these methods, and how to recognise inappropriate applications.

Multivariate approaches are widely used for:

  • Summarising complex patterns in biological data.
  • Identifying groupings or patterns among samples or species.
  • Testing statistical hypotheses involving multivariate datasets.

3 What you will do

In this part of BEDA, you will:

  1. Practise using key multivariate techniques with sample datasets provided during practical sessions.
  2. Apply these techniques to data you collect and collate in groups.
  3. Compare the results of different multivariate methods to see how each highlights different features of the same dataset.

Although best scientific practice recommends selecting appropriate analyses before data collection, this exercise lets you try several analytical approaches to better understand their application and interpretation.

4 Analyses and software

We will mainly use jamovi for these analyses. If you prefer working in R, complete scripts for all the methods covered will be available on Canvas for use in RStudio. For nMDS, ANOSIM, PERMANOVA, and SIMPER, we will primarily use the MISO module in jamovi.

These methods serve different purposes. PCA and nMDS help us summarise or visualise patterns in multivariate data, such as environmental measurements or species abundances across sites. ANOSIM and PERMANOVA let us test hypotheses about these patterns, while SIMPER describes how individual variables contribute to differences between groups.

Principal components analysis (PCA)

Principal components analysis (PCA) reduces the complexity of a dataset by transforming the original variables into a smaller set of uncorrelated variables called principal components. These components capture as much of the variance in the original data as possible.

PCA is especially useful for analysing habitat data, where multiple environmental variables can be summarised into a few components that describe the main gradients in the data.

Non-metric multidimensional scaling (nMDS)

Non-metric multidimensional scaling (nMDS) is an ordination technique used to visualise patterns in multivariate data. It represents samples in a low-dimensional space based on their similarity or dissimilarity, usually measured using Bray-Curtis dissimilarity. It helps us see groupings or gradients in community composition or other multivariate datasets.

Analysis of similarities (ANOSIM)

Analysis of similarities (ANOSIM) tests whether groups of samples differ in composition by comparing similarities within and among groups. It uses ranked dissimilarities and is best suited to simple experimental designs.

The output includes a global R statistic and a p-value.

Permutational multivariate analysis of variance (PERMANOVA)

Permutational multivariate analysis of variance (PERMANOVA) can accommodate more complex experimental designs than ANOSIM. It uses permutation-based ANOVA on a resemblance matrix and can include multiple fixed and random factors.

It can test main effects and interactions, and accommodate nested designs.

Similarity percentages (SIMPER)

Similarity percentages (SIMPER) summarises how much each variable, such as a species, contributes to the average dissimilarity between groups.

It calculates the percentage contribution of each variable, helping us interpret the biological meaning of differences between groups. SIMPER is descriptive; it is not itself a significance test.
